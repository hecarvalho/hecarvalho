## Projeto em destaque

### ADQL UI

Design system e editor visual para criação de cards analíticos do projeto **Além das Quatro Linhas**.

O projeto inclui:

- componentes HTML, CSS e JavaScript;
- editor visual próprio;
- cards de comparação estatística;
- radar de métricas;
- construtor de tabela;
- capa editorial para matérias;
- exportação em PNG e HTML;
- fluxo manual com ChatGPT para geração de cenas táticas;
- base preparada para futura migração com Electron;
- uso de Node.js e scripts auxiliares durante o desenvolvimento.

Repositório: [`adql-ui`](https://github.com/hecarvalho/adql-ui)
